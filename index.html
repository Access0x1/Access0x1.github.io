What it is

One shared, multi-tenant router serves every merchant. A payment is priced USD-to-token inside the settlement transaction via a Chainlink feed, an exact fee is split atomically, and net value is pushed to the merchant — all in one tx. The contract never holds merchant funds.

  • Payments — non-custodial, USD-priced, exact fee split, all in one tx
  • Commerce — subscriptions, bookings, invoices, gift cards, zero-custody NFT sales
  • Identity + agents — sign-once budget-scoped sessions; World ID / ENS / OIDC verified checkout
  • Your own token — non-custodial factory for a loyalty / credit / closed-loop token
